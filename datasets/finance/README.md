# Finance dataset

A financial schema for SQL problems: accounts, transactions, budgets, invoices, and investments. Deterministic seed for reproducible tests.

## Tables

- `accounts` — 5 bank accounts
- `transactions` — 10 transactions (deposits, withdrawals, transfers)
- `budgets` — 5 department budgets for fiscal year 2024
- `invoices` — 5 vendor invoices with payment status
- `investments` — 4 investment funds with principal and current value
