# Ops/Logistics dataset

A logistics and operations schema for SQL problems: warehouses, shipments, inventory, carriers, and shipment-carrier assignments. Deterministic seed for reproducible tests.

## Tables

- `warehouses` — 4 warehouse locations
- `shipments` — 8 shipments with various statuses
- `inventory` — stock levels per warehouse
- `carriers` — 4 shipping carriers
- `shipment_carriers` — carrier assignments with costs
